How to Build Your Pure Native APK

Method 1: GitHub Actions (Cloud Auto-Build)

  1. Push changes: git push origin main
  2. Go to your GitHub repo's Actions tab.
  3. Select StreamX Native Android CI/CD.
  4. Download StreamX-release-apk directly.

Method 2: Android Studio (Local Development)

  1. Open Android Studio > Open Project.
  2. Select the StreamX directory.
  3. Let Gradle sync dependencies (JDK 17).
  4. Click Run (Shift + F10) on emulator or connected phone.
